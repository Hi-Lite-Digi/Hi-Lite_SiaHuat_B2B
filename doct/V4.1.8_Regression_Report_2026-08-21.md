# V4.1.8 regression report

Date: 21 August 2026 (Singapore time)

## Scope

This release replays the long customer-style conversation that previously broke product memory and ordering. The flow intentionally changes requirements, asks for more options, asks Claire to recommend one, switches product families, corrects a size constraint, selects a numbered option, changes quantity, and requests a stock-qualified alternative.

## Issues fixed

- A later Japanese-knife request no longer revives an earlier Damascus requirement.
- “Can you share a few?” keeps the active product constraints and excludes products already shown.
- Natural variants such as “Can you share a few more options?” are handled the same way and cannot repeat the previous cards.
- “Recommend one” selects from the latest displayed options instead of starting a generic search.
- Short follow-ups can no longer attach themselves to an old clarification from a previous product enquiry.
- “You are broken” acknowledges the bad reply while retaining the active product task.
- Wok searches support “around / closest size” and iron or carbon-steel fallback constraints.
- “Forget 36cm” removes the stale size constraint without losing the wok, material, or quantity.
- “Option 2 please, 4 pieces” binds to the latest numbered product and keeps the quantity.
- Clarification-only replies no longer erase displayed-product or quantity memory.
- The redundant n8n background sync request was removed; normal conversational turns still use the n8n-backed chat route with the full transcript.
- Once a catalogue-grounded reply is ready, its unused parallel n8n fetch is cancelled so it cannot occupy Vercel capacity until the workflow timeout.
- PDF export uses jsPDF’s supported save path and was verified by a real downloaded file.
- Low-stock alternatives now stay in the same product family. A wok shortage can no longer return a shabu-shabu pot.
